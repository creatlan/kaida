## Повторная загрузка

Перед запуском в Supabase должно быть отключено подтверждение email:
`Authentication → Providers → Email → Confirm email`.

Из каталога `frontend` выполните:

```powershell
npm.cmd run seed:demo
```

Скрипт можно запускать повторно: существующие аккаунты используются заново, а квизы с такими же названиями не дублируются.
